How It Works
Kadane's algorithm breakdown
1

Initialize

Set maxSum and currentSum to 0. Track window boundaries with maxStart, maxEnd, and currentStart.

2

Iterate

Scan each element left to right. Add the current element to running currentSum.

3

Update Maximum

If currentSum exceeds maxSum, update maxSum and record the window boundaries [maxStart, maxEnd].

4

Reset on Negative

If currentSum drops below zero, reset it to 0 and move currentStart to the next index. Any extension would only decrease the total.

5

Return Result

Extract the subsequence from arr[maxStart:maxEnd]. If all elements are negative, returns empty array (sum 0).

function maximumSubsequence(arr) { if (!arr || arr.length === 0) return []; let maxSum = 0, currentSum = 0; let maxStart = 0, maxEnd = 0, currentStart = 0; for (let i = 0; i < arr.length; i++) { currentSum += arr[i]; if (currentSum > maxSum) { maxSum = currentSum; maxStart = currentStart; maxEnd = i + 1; } if (currentSum < 0) { currentSum = 0; currentStart = i + 1; } } return arr.slice(maxStart, maxEnd); }
